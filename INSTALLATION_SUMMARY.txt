QUICK START (Copy & Paste):
  
  1. Verify Java & Maven installed:
     java -version
     mvn -version

  2. Create Firebase project:
     - Go to https://console.firebase.google.com
     - Create new project
     - Enable Realtime Database (Test Mode)
     - Download service account JSON
     - Copy database URL

  3. Set environment variables (Mac/Linux):
     export FIREBASE_DATABASE_URL=https://your-project-default-rtdb.firebaseio.com
     export FIREBASE_SERVICE_ACCOUNT_PATH=/path/to/firebase-json.json
     export MAIL_PASSWORD=test
     export ADMIN_PASSWORD=admin123

  4. Start the app:
     cd /Users/wizo/Yammay_Blacksmith/artisan-iron-web
     ./mvnw spring-boot:run

  5. Open browser:
     http://localhost:8080

TROUBLESHOOTING:
  
  Port 8080 in use?
    → Kill the process: lsof -i :8080 && kill -9 <PID>
    → Or change port in application.yml
  
  Firebase connection failed?
    → Check FIREBASE_DATABASE_URL is set correctly
    → Check service account JSON file path exists
    → Check Realtime Database is enabled in Firebase console
  
  Maven not found?
    → Install from https://maven.apache.org/download.cgi
  
  Java not found?
    → Install Java 17+ from https://www.oracle.com/java
